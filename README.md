# Travel Destination Explorer

A responsive web application to explore popular travel destinations, filter by name, sort by estimated travel cost, and dynamically calculate the total estimated trip budget.

## Features

- **Destination Directory**: Browse popular destinations including Paris, Tokyo, Istanbul, and Dubai with details and estimated costs.
- **Real-Time Search**: Filter destinations instantaneously by name.
- **Sort by Cost**: Sort available travel spots from lowest to highest cost.
- **Dynamic Cost Calculator**: Automatically sums and displays the total estimated cost for all currently displayed destinations.
- **Responsive Design**: Clean UI optimized for mobile and desktop screens.

## Tech Stack

- **HTML5**: Semantic document structure and accessibility attributes.
- **CSS3**: Modern responsive styling and card layout.
- **JavaScript (ES6+)**: Functional programming techniques (`filter`, `map`, `reduce`), event handling, and DOM manipulation.

## Getting Started

Simply open `index.html` in any modern web browser or use a live server extension.
